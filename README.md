# School App

نظام توزيع الاحتياطي للمشرفين.

## التشغيل
1. افتح المجلد في الحاسوب.
2. افتح `index.html` في المتصفح.
3. من الهاتف، افتح نفس رابط الشبكة أو استخدم Live Server.
4. اضغط على القائمة في المتصفح ثم "إضافة إلى الشاشة الرئيسية".

## مميزات التطبيق
- إدارة الغياب اليومي
- توزيع احتياطي تلقائي
- جدول الحصص الأسبوعي
- إدارة المدرسين
- تقارير شهرية
- قراءة جدول الحصص من صورة باستخدام Tesseract.js
- حفظ البيانات محلياً في المتصفح

## ملاحظة
هذا التطبيق يعمل كـ PWA (تطبيق ويب قابل للتثبيت على الهاتف).
